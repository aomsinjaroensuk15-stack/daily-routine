# ตารางประจำวัน · คะแนนประจำสัปดาห์

แอปตารางเวลาประจำวันสำหรับผู้ปกครอง ใช้กดหักคะแนนเมื่อลูกลืมทำสิ่งที่ต้องทำ คะแนนที่หายไปจะกลายเป็นบทลงโทษเรื่องเวลาเล่นเกม ทำให้ตารางชัดเจนและไม่ลืม

### [เปิดแอปที่นี้](https://aomsinjaroensuk15-stack.github.io/daily-routine/)

เป็นไฟล์เดียว (`index.html`) ไม่ต้องติดตั้ง ไม่ต้องมีเซิร์ฟเวอร์ เปิดบนมือถือหรือคอมได้เลย ผู้ใช้คือผู้ปกครอง

## ภาพรวม

แอปมี 4 แท็บ:

| แท็บ | คะแนนเต็ม | รีเซ็ต |
|---|---|---|
| วันไปเรียน | 100 | จันทร์ 00:00 |
| วันหยุด | 50 | จันทร์ 00:00 |
| ป้องกันการลืม | 50 | เสาร์ 00:00 |
| เวลาเล่นเกม | – | – |

ทุกแท็บที่มีคะแนนมีปุ่ม **เพิ่มคะแนน** และ **รีเซ็ตคะแนน** (รีเซ็ตจะถามยืนยันก่อน)

เวลาทั้งหมดคิดตามเขตเวลาไทย (UTC+7)

## วันไปเรียน (จันทร์–ศุกร์)

ตารางหลังกลับบ้านแต่ละวัน แต่ละ item ที่ต้องทำมีปุ่ม **หักคะแนน** อยู่ท้ายแถว กดได้ 1 ครั้งต่อ item ต่อวัน และกด "ยกเลิก" ได้

| เวลา | item | หักคะแนน |
|---|---|---|
| ก่อน 17:00 | เอาขยะไปทิ้ง | 10 |
| 16:30–17:00 | อาบน้ำ | 15 |
| 17:00–18:00 | กินข้าว | 15 |
| ช่วงกินข้าว | เติมน้ำแข็งในแก้ว | 10 |
| 18:00–19:00 | ทำอะไรก็ได้ (ไม่ใช้โทรศัพท์/คอม) | – |
| 19:00–20:00 | เล่นเกม (optional) | – |
| 20:00–21:00 | ทำอะไรก็ได้ (ไม่ใช้โทรศัพท์/คอม) | – |
| ก่อนนอน | แปรงฟัน | – |
| 21:00 | เข้านอน (หลับก่อน 21:30) | 15 |

วันศุกร์นอนก่อน 22:00

**นับคะแนนจบ ศุกร์ 22:00** หลังจากนั้นปุ่มหักถูกล็อก และผลสรุปจะแสดงจนถึงวันอาทิตย์

| คะแนนตอนจบ | บทลงโทษ (หักจากเวลาเกมเสาร์–อาทิตย์) |
|---|---|
| 100 | ไม่มี |
| ต่ำกว่า 100 | หัก 1 ชม. 1 นาที ทันที |
| 98 หรือต่ำกว่า | หักเพิ่ม 1 นาทีต่อทุกคะแนนที่ต่ำกว่า 98 (98 − คะแนนสุดท้าย) |
| 20 หรือต่ำกว่า | ไม่มีเวลาเล่นเกมเลยทั้งวันหยุด |

ตัวอย่าง: คะแนน 90 → หัก 61 + 8 = 69 นาที

## วันหยุด (เสาร์–อาทิตย์)

ตารางยาวตั้งแต่เช้าจนนอน แต่ละ item ที่หักได้ **หัก 10 คะแนน** ยกเว้นแพ็คเช้า **หัก 20**

| เวลา | item | ปุ่มหัก |
|---|---|---|
| ก่อน 09:30 | แพ็คเช้า (ตื่นนอน, แปรงฟัน, กินข้าวเช้า, เติมน้ำแข็งในแก้ว) | 20 |
| 09:30–10:30 | เล่นเกม (optional) | – |
| 10:30–11:30 | ฝึกฝนคำศัพท์ | 10 |
| 11:30–12:00 | เอาขยะไปทิ้ง + ทำอะไรก็ได้ | 10 |
| 12:00–13:00 | กินข้าวเที่ยง | 10 |
| 13:00–14:00 | ทำอะไรก็ได้ | – |
| 14:00–15:00 | เล่นเกม (optional) | – |
| 15:00–16:30 | ทำอะไรก็ได้ | – |
| 16:30–17:00 | อาบน้ำ | 10 |
| 17:00–18:00 | กินข้าวเย็น | 10 |
| ช่วงกินข้าว | เติมน้ำแข็งในแก้ว | 10 |
| 18:00–19:00 | ทบทวนคำศัพท์ (จากตอนเช้า) | 10 |
| 19:00–20:00 | เล่นเกม (optional) | – |
| 20:00–21:00 | ทำอะไรก็ได้ | – |
| ก่อน 21:00 | แปรงฟัน | – |
| 21:00–22:00 | เข้านอน (หลับก่อน 22:00) | 10 |

เวลาเกมวันหยุดปกติคือ **3 ชั่วโมงต่อวัน**

**ผลของคะแนนวันหยุด:** ทุก 1 คะแนนที่หายไป ตัดเวลาเกมของ **วันไปเรียนทุกวัน (จันทร์–ศุกร์) ของสัปดาห์ถัดไป** วันละ 1 นาที (ช่องเกมวันไปเรียนมี 60 นาที) ถ้าเหลือ 50 คะแนนเต็ม ไม่มีผล

## ป้องกันการลืม

คะแนนเต็ม 50 ใช้เมื่อลูกทำของหาย ผู้ปกครองกรอกจำนวนคะแนนที่หักเอง (โน้ตไม่ใส่ก็ได้) และลบรายการทีละอันได้ รอบเริ่มเสาร์ 00:00 และจบเสาร์ 00:00 ถัดไป

**ผลของคะแนน:** ทุก 1 คะแนนที่หายไป ตัดเวลาเกมของ **วันหยุดทุกวัน** วันละ 1 นาที มีผลตั้งแต่เสาร์ที่รอบนั้นจบ ถ้ายังเหลือ 50 คะแนนเต็ม ไม่มีผล

## เวลาเล่นเกม 7 วันข้างหน้า

ลิสต์เวลาเกมที่เหลือของแต่ละวัน (เริ่มจากวันนี้) พร้อมวิธีคิด เช่น `180 นาที − 15 (ของหาย) − 69 (บทลงโทษวันไปเรียน)`

- วันไปเรียน = 60 − ตัดจากคะแนนวันหยุด
- วันหยุด = 180 − ตัดจากป้องกันการลืม − บทลงโทษวันไปเรียน (บทลงโทษหักจากวันเสาร์ก่อน แล้วค่อยหักวันอาทิตย์)
- ค่าที่ยังไม่แน่นอน (คะแนนยังไม่จบการนับ หรือเป็นสัปดาห์หน้า) มีป้าย **ประมาณการ** และเปลี่ยนตามคะแนนปัจจุบัน

## หยุดชั่วคราว และไปเที่ยว

ในแท็บวันไปเรียน แต่ละวันตั้งโหมดได้:

- **หยุดชั่วคราว 1 วัน**: วันนั้นใช้ตารางวันหยุด และหักจากคะแนนวันหยุด
- **ไปเที่ยว**: ยกเลิกตารางวันนั้น ไม่หักคะแนน เวลาเกมวันนั้นเป็น 0 (ในแท็บวันหยุดตั้งไปเที่ยวได้เช่นกัน)
- **กลับมาทำปกติ**: ย้อนกลับได้ตลอด

## ข้อมูลและการสำรอง

- ข้อมูลเก็บใน `localStorage` ของเบราว์เซอร์ที่เปิดใช้ ไม่มีการส่งออกไปที่ไหน
- ถ้าล้างข้อมูลเบราว์เซอร์หรือเปลี่ยนเครื่อง ข้อมูลจะหาย ใช้ปุ่ม **สำรองข้อมูล** (ดาวน์โหลดไฟล์ JSON) และ **กู้คืนข้อมูล** ที่ท้ายหน้า
- เก็บประวัติคะแนนย้อนหลัง 8 สัปดาห์
- คะแนนรีเซ็ตเองเมื่อเปิดแอปหลังเวลารีเซ็ต

## ทดสอบโดยจำลองเวลา

เติม `?now=` ท้าย URL เป็นเวลาไทย เช่น

```
.../daily-routine/?now=2026-10-23T21:59
```

โหมดนี้จะไม่บันทึกข้อมูลจริง และมีแถบ "โหมดทดสอบเวลา" แสดงอยู่ด้านบน

## โฮสต์บน GitHub Pages

1. วางไฟล์ `index.html` ไว้ที่ root ของ repo
2. ไปที่ Settings → Pages
3. เลือก Source เป็น Deploy from a branch แล้วเลือก branch `main` และโฟลเดอร์ `/ (root)`
4. รอสักครู่ แอปจะเปิดได้ที่ลิงก์ด้านบน
